# KelanaAI

AI Travel Planner — Sesi 1: Trip Summary Generator (Python Console App)

## Struktur Proyek

```
kelana-ai/
├── README.md
├── backend/
│   └── main.py
└── frontend/
    └── .gitkeep
```

## Cara Menjalankan

```bash
cd backend
python main.py
```

Program akan meminta input berikut:

- `destination` — nama destinasi (string)
- `country` — negara tujuan (string)
- `days` — lama perjalanan dalam hari (integer)
- `budget` — anggaran perjalanan (float)
- `currency` — mata uang (string)
- `travel_month` — bulan perjalanan (string)

Lalu menampilkan ringkasan perjalanan yang terformat rapi.
